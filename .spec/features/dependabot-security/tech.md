# Feature: Dependabot Security Updates — Architecture

A dependency-only change touching `package.json` and `pnpm-lock.yaml`. Each open
alert is reconciled against the **currently locked** version and assigned one of
four vectors: direct bump, unused-dep removal, scoped `pnpm.overrides`, or
dismiss-with-reason. The work is **sequenced** (bump → regenerate lock → re-derive
the residual override set) rather than authored blind, because the `vite` and
`vitest` bumps cascade-fix several transitives on their own.

## Strategy: sequence, don't author overrides blind

```text
1. Direct bumps  → vite 7.3.2, vitest 3.2.6 (+coverage-v8), postcss 8.5.10, uuid 11.1.1
2. Remove unused → jotai-devtools, @tanstack/react-form, @tanstack/zod-form-adapter
3. pnpm install  → regenerate lock; the vite+vitest cascade clears picomatch/rollup/esbuild-0.21/transitive-postcss
4. Re-derive     → re-run `gh ... dependabot/alerts` + `pnpm why`; add overrides ONLY for what survives
5. Dismiss       → svelte (dev-only), esbuild Deno-only, in the Dependabot UI with reason
```

**Override set as shipped** (re-derived after step 3 regen — the `vite` bump did *not*
auto-move `rollup`/`picomatch`, and `pnpm audit` surfaced a `brace-expansion@5` advisory
not in GitHub's original list, via `@vitest/coverage-v8 → test-exclude → minimatch@10`):

## Verification path

There is no automated UI/runtime test — the data-layer Vitest suite (mapper, builder,
dateUtils, validation) does not exercise the React surface, and `pnpm build` succeeds
even when a runtime API is broken. So verification is layered:

1. `pnpm check` — Biome lint/format (`./src ./tests`).
2. `pnpm build` — Vite build + TypeScript strict (`tsc`) — catches type/contract breaks.
3. `pnpm test` — Vitest data-layer suite — primary validator for the **vitest 2→3** bump.
4. **Manual Obsidian smoke** (required, not optional) — load the plugin in `dev-vault`, create + edit a task via the form, switch Table/List/Board. Confirms removal of `jotai-devtools`/form deps and overrides didn't regress runtime.

## Risks & Mitigations

| Risk | Mitigation |
|---|---|
| `vitest` 2→3 breaking changes | Small data-layer suite; `pnpm test` validates. The one accepted major (dev-only, low blast radius). |
| An override forces a version a consumer rejects | Re-derive after regen (step 4); scope `minimatch@9` so the `10.2.5` consumer is untouched; gate on `pnpm build && pnpm test`. |
| Removing an "unused" dep that is actually dynamically loaded | Verified **zero** references repo-wide (`grep src/ tests/ *.cjs`); regen + build + test confirm. |
| `uuid` ESM-only major (PR #42's 14) breaks the CJS bundle | Stay on `11.1.1` (patch) — clears the alert without the major. |
| Dismissed alert later becomes triggerable (e.g. `@vitest/ui` added) | Dismissals are reasoned and scoped to current usage; re-evaluate if the toolchain changes. |
